A 0x88 alpha-beta chess engine: 150k nodes/move, check extension, quiescence, LMR and a transposition table. Mean Elo 1,475 across three practice trials (1,430 / 1,497 / 1,497) vs the sunfish-4k baseline mean of 1,360. `main.py` loads the lzma-packed engine from `engine.lzma`.

## Run it

```sh
python3 main.py
```
